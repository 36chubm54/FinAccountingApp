# Ledgera v3 Alpha Archive

This folder contains historical acceptance records for the `v3.0.0-alpha`
cycle.

These documents are not the active beta backlog. Use them as evidence for what
was closed during alpha.1-alpha.4, including validation commands, rollout
boundaries, and deferred scope captured at the time each alpha milestone was
merged.

Active beta planning lives in `docs/v3_beta_plan.md`.
